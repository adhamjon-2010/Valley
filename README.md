# Farg'ona Sport - 3D Xarita & Multi-Step Sport Ilovasi
### (Yoshlarobod • Vodil • Novkat)

Farg'ona tumanidagi sport zallari va sun'iy futbol maydonlarini band qilishga mo'ljallangan to'liq ishlaydigan bitta faylli interaktiv sport ilovasi frontend loyihasi.

🌐 **Onlayn havola (Jonli sayt):** [https://adhamjon-2010.github.io/volley/](https://adhamjon-2010.github.io/volley/)  
📦 **GitHub Repozitoriysi:** [https://github.com/adhamjon-2010/volley](https://github.com/adhamjon-2010/volley)

---

## 🚀 Qanday ishga tushirish mumkin?

1. **Onlayn brauzerda ochish:**
   - [https://adhamjon-2010.github.io/volley/](https://adhamjon-2010.github.io/volley/) havolasini istalgan telefon yoki kompyuterda oching.
2. **Mahalliy (Local) ochish:**
   - Papkadagi `index.html` faylini istalgan brauzerda ikki marta bosib oching.
3. **React loyihada ishlatish:**
   - `App.jsx` faylini React loyihangizning `src/` papkasiga ko'chiring (`npm install lucide-react`).

## 🌟 Asosiy Imkoniyatlar:
1. **Kirish qismi (1-bosqich):** Ism, telefon raqami (majburiy), yosh va hududni kiritish.
2. **Xaritada joylashuv (2-bosqich):** Xaritadan yoki tezkor tugmalar orqali turgan joyini belgilash.
3. **3D Izometrik Sport Xaritasi (3-bosqich):** Maktab sport zallari va sun'iy maydonlar 3D modellari, burish va 2D/3D rejimlari.
4. **Sport turlari filtri:** Voleybol (birlamchi), Futbol, Basketbol.
5. **O'yinlar va Zal to'lovini taqsimlash kalkulyatori:** (+ / - bilan kishi boshiga to'lov hisobi, Payme, Click, Naqd).
6. **Dark / Light Mode:** Tungi va kunduzgi mavzular.
7. **Yon tomon profil paneli:** Rasm yuklash, 2 soat va 30 daqiqa oldin avtomatik eslatmalar.
